# Open Skills Framework

This repository provides an open, machine-readable skills taxonomy intended to make
competency data interoperable across human-resource and learning platforms.

The framework models each skill as a node with a stable identifier, a definition, and links
to the broader skills that contain it, so that consumers can reason about related abilities.

Governance is handled through versioned releases, where each change to a skill definition is
recorded so that downstream systems can migrate deliberately rather than silently.
